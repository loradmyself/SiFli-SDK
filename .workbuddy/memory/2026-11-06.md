
## EPD SPV/CKV 时序延迟分析（B082A05_EPD, 只出方案未改码）
- 现象：LCDC EPD TCON 直出的 GDCLK(CKV) 与 GDSP(SPV) 同时翻转，面板要求 SPV 相对 CKV 边沿有少量延迟。
- 关键结论：TCON_IF_CONF1~4 只有极性/长度字段，无 SPV 延迟字段；GDSP/GDCLK 完全由 LCDC TCON 硬件状态机生成，B082A05_EPD.c 的 cfg.epd 无法表达该延迟。
- 方案：PTM1 接管 GDSP —— GDSP pad 复用改 PTM1_CHx，PTM 程序 WAIT CKV 边沿 → PTM_WAIT Dly 延迟 → PTM_IO 翻转输出。
- 修改层：HAL 层为主（bf0_hal_lcdc.c EPD 分支 ~L413-443 加钩子；bf0_hal_lcdc_aux.c 参照 DPI_HW_FSM_START PTM 框架加 EPD_HW_FSM_START；EPD_LCD_CFG 加 GDSP_delay 字段），面板驱动层只填参数，板级 pinmux 改 GDSP 复用。delay=0 保持原直驱。
- 待确认：57x TCON 是否有隐藏 GDSP 相位配置（如 GSTA 实际含义），若有则屏幕驱动层改参即可。

### B082A05 规格书时序核对（A0 版 7.4 表）
- 7.4 Panel AC Characteristics：tSU>=100ns、tH>=100ns、twL/twH>=500ns、fckv<=200kHz、边沿<=100ns；XCL tcy 16.67~50ns（20~60MHz），40MHz 合规。CKV/SPV 参数为绝对 ns，与 XCL 频率无关。
- SPV 低宽 = tSU + twL + tH，GATE OUTPUT 图跨约 2 个 CKV 周期，与实测 ~21us 一致 → WIDTH 维持 20000ns。
- DELAY 公式：T0(FMARK→CKV 下降沿实测) − tSU(建议 200ns)。已把手册映射写进 board.conf 注释与 Kconfig.help，编译通过（294,496B 不变）。
- LA 截图实测：CKV 低脉冲 ~5us、周期 ~12us（约 83kHz），SPV 低 ~21us，下降沿在 CKV 下降沿前、上升沿在其后（满足 tSU/tH）。

### 按原厂 patch 重做 SPV PTM 相位（替换我此前的 HAL 方案）
- 我此前的 HAL 层 PTM 方案（EPD_LCD_CFG 加 GDSP_ptm_* 字段 + aux 里 EPD_GDSP_PTM_Init）已被用户整体回退，全部痕迹已清空。
- 用户提供 shared-reader E0470A03 的 ptm-from-shared-reader.patch，核心思路更优：PTM 自己写 LCDC COMMAND START（PTM_STM），两个 SPV 沿都锚定 CKV 上升沿+固定相位（WAIT_PA40 采样 pad，不改 TCON mux），程序每帧跑一遍即 END+EVT0，帧回调检查 EVT0。
- 合入内容：
  1. bf0_hal_lcdc.h/.c 新增 weak HAL_LCDC_EPD_StartHook()，在 SendLayerData 的两处 COMMAND=START 前调用（EPD 面板可接管 START）。
  2. B082A05_EPD.c 移植 patch 全套（configure/release/prepare/arm/hook/complete），适配：WAIT_PA27 采样 CKV（PA27 保持 TCON_GDCLK mux）、PA25 复用 PTM1_CH0（prepare 内 remux）、接口判 LCDC_INTF_EPD_16BIT、SPV_PHASE_NS=3500（用户指定 CKV 高电平一半 ~3.5us，原 patch 面板用 7550）。
  3. 集成点：epd_flush_begin 里 prepare（失败则告警回退 TCON），StartFrame 里 arm（失败中止序列），LCDC_SendLineCpltCbk 里 complete+统计打印+release。
  4. SConscript 加 EPD_SPV_PTM_PHASE 编译开关（默认 1，EPD_SPV_PTM_PHASE=0 可对比 TCON 直出）；msh 命令 epd_spv_phase 0/1。
  5. patch 的 HAL 层无需其它改动（原作者针对新 SDK，我们 SDK 缺 StartHook，已补）。
- 验证：scons --board=dpi-hdk_lb57gyd7n6_epd 编译通过，bin 295,048B；nm 确认 main.elf 中 StartHook 为面板驱动强符号、PTM 代码编入。

### PA25/PA27 调换跟进
- 用户自行发现 CKV 极性接反并已改好；同时板级 pinmux 已调换：PA25→LCDC1_TCON_GDCLK（CKV）、PA27→LCDC1_TCON_GDSP（SPV 默认）。
- 上板波形像素级测量确认 PTM 程序工作精确：SPV 两沿 = CKV 上升沿 + 3.53us（3500ns 配置），间隔恰一个 CKV 周期；此前波形异常是 CKV 极性反所致。
- B082A05_EPD.c 同步适配调换：WAIT_PA27→WAIT_PA25（PTM 采样 CKV，PA25 保持 TCON_GDCLK mux）；SPV 输出 PAD_PA25→PAD_PA27 复用 PTM1_CH0（prepare 内 remux）。编译通过。
