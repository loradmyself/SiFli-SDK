FFmpeg AAC Encode/Decode Example

This directory contains test audio files for the AAC example.
Place .aac or .mp3 files here if you want to test playback.

Shell commands available after boot:
  aac_test [seconds]  - Record mic -> AAC encode -> decode & play
  aac_enc  [in] [out] - Encode raw PCM to AAC file
  aac_play [file]     - Decode AAC file and play to speaker
  aac_stop            - Stop current playback
